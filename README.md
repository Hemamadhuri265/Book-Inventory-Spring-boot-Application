# Book-Inventory-Spring-boot-Application
📢 Hey! Here is my new Project Update using Spring Boot 🚀
📚 TreasureShelf – Book Inventory Management System
 
Tech Stack: Spring Boot | Hibernate | Thymeleaf | MySQL | Lombok | HTML | CSS

I built TreasureShelf, a complete Book Inventory Management System using Spring Boot. This web application allows users to register books with details like name, author, price, and image, view them in a public library, and add favorite books to a personal section called 'My Treasure'. Users can also edit, delete, or add books.

🔍 Key Features:
📝 Book registration form with fields for name, author, price, and image upload (image saved locally, path stored in MySQL).
📚 Library view that dynamically displays all books using Thymeleaf.
💖 'My Treasure' section where users can save favorite books (handled with a boolean flag).
🔁 Full CRUD operations (Create, Read, Update, Delete) on books.
⚙️ Backend powered by Spring Boot, Hibernate for ORM, and Lombok for cleaner code.
🎨 Clean and animated UI built from scratch using HTML and CSS (no Bootstrap or external UI frameworks).

✅ What I Learned:
This project gave me hands-on experience in full-stack development, including file handling, dynamic content rendering, and efficient database management using Java-based technologies.
